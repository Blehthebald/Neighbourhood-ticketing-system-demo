# Neighbourhood-ticketing-system-demo
This is a rough demo of a neighbourhood ticketing system. Currently, this system is not being hosted on a server and must be run locally on your own computer. Some features are not fully developed.
## Applications/Services used
- leaftlet.js : geotagging and interactive map
- cloudinary : image upload and storage
- node.js : hosting on local computer

## Features:
1) Geotagging tickets
2) Interactive map with geotagged tickets
3) Searching up public tickets by name
4) Filtering ticket by tag (broken)
5) Looking at own tickets (there are not user accounts currently so this is undeveloped)
